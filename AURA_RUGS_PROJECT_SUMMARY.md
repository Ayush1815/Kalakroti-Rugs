# 🏺 Kalakroti Rugs: Premium E-Commerce Platform Summary

**Kalakroti Rugs** is a boutique, high-end e-commerce platform designed for the curation and sale of heritage-grade rugs and carpets. The platform prioritizes **editorial storytelling**, **architectural aesthetics**, and **technical craftsmanship data**.

---

## 🛠️ The Tech Stack

### 1. Frontend (The Visual Experience)
*   **Architecture**: Vanilla HTML5 / JavaScript (ES6+).
*   **Styling**: **Tailwind CSS (CDN)** for rapid, utility-first luxury design.
*   **Typography**: Premium serif/sans-serif pairing (**Playfair Display** & **Inter**) via Google Fonts.
*   **Interactivity**: 
    *   **Custom Animation Engine**: CSS-driven "Center-Out" line animations and hardware-accelerated hero sliders.
    *   **Responsive Grid**: Multi-breakpoint cinematic layouts (5-column room discovery).

### 2. Backend (The Storytelling Engine)
*   **Framework**: **Django 5.x** (Python 3.11+).
*   **API Layer**: **Django Rest Framework (DRF)** for high-performance JSON delivery.
*   **Database**: **SQLite** (Development) with a production-optimized schema.
*   **Media Management**: Local asset pipeline serving high-fidelity photography from `/images/`.

---

## 💎 Core Project Features

### 🏺 Immersive Luxury UI
*   **Heritage Cream Design System**: A curated palette of Cream, Gold, Rust, and Heritage Dark.
*   **Dynamic Hero Gallery**: An auto-scrolling (3s interval) cinematic slider featuring premium local assets.
*   **Shop By Environment**: A tabbed, 5-column cinematic grid discovery system (Living, Bedroom, Dining, etc.).
*   **Frosted Glass Navigation**: Slim, opaque dropdown menus with architectural blur effects.

### 🏛️ Production-Ready Backend
*   **Deep Storytelling Schema**: Captures luxury data points like **Knot Density** (up to 1.2M), **Weave Type**, and **Artisan Heritage Stories**.
*   **Curated Admin Dashboard**: A bespoke, frontend-driven management interface (`admin.html`) connected via API for real-time curation.
*   **Full CRUD Integration**: Active database connectivity for reading, editing, and publishing heritage pieces.
*   **E-Commerce Essentials**: Integrated SKU management, featured flags, and stock status tracking.
